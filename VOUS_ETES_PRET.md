## Par ou commencer?

### 1. Demarrage Rapide (5 minutes)

```bash
cd fleuriste-site
npm install
npm run dev
```

Ouvrez http://localhost:3000 pour voir le site!

### 2. Configuration Complete

Suivez la **CHECKLIST.md** etape par etape:
1. Configuration Supabase (15 min)
2. Configuration LemonSqueezy (15 min)
3. Ajout de vos images (10 min)
4. Personnalisation du contenu (10 min)
5. Deploiement sur Vercel (10 min)

**Temps total estime: ~1 heure**
