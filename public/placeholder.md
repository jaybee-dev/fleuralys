Pour le développement, vous devez ajouter vos propres images dans le dossier `/public/images/`.

## Recommandations

- Format: JPG ou WebP
- Dimensions recommandées:
  - Bouquets: 800x800px (format carré)
  - Galerie: 1200x800px (paysage)
  - Articles: 1200x630px (format Open Graph)
- Optimiser les images avant de les ajouter (utiliser TinyPNG ou similaire)

## Alternative: Images de démonstration

En attendant vos propres images, vous pouvez utiliser des images de démonstration depuis:
- [Unsplash](https://unsplash.com/s/photos/flowers)
- [Pexels](https://pexels.com/search/flowers)
- [Placeholder services](https://placeholder.com)

Exemple d'URL placeholder à utiliser temporairement:
```
https://placehold.co/800x800/e25578/white?text=Bouquet+Romance
```
